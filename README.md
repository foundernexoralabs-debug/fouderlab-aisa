# founderlab-aisa (FounderLab AI — Built for founders, builders, and creators. Fast, smart, and fully open. Powered by local models and top-tier AI providers.)

## What IronTrack AI Does IronTrack AI helps users: - Track workouts - Log exercises, sets, reps, and weights - Monitor strength progress over time - Track body measurements - Track body weight and body fat changes - Create meal plans - Track calories and macros - Follow bodybuilding goals - See progress charts - Save progress photos - Build weekly training plans - Stay consistent with habits - Get AI-powered improvement suggestions

## Core Features ### Workout Tracking Users can create and track workouts for: - Chest - Back - Shoulders - Arms - Legs - Core - Full body - Push / Pull / Legs - Upper / Lower - Custom split routines Each workout can include: - Exercise name - Sets - Reps - Weight - Rest time - Notes - Difficulty - Personal records
